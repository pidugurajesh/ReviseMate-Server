\# ReviseMate


Three-environment deployment workflow: dev → test → main


ReviseMate is a web application for students to manage their study activities and learning progress.



\## Features



\- User authentication

\- Dashboard

\- Revision management

\- Todo management

\- Studied topic tracking

\- Analytics

\- Profile management



\## Technologies



\### Frontend

\- React

\- Vite

\- JavaScript

\- CSS



\### Backend

\- Node.js

\- Express.js

\- MongoDB
